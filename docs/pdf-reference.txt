Before you start
This isn't a list of prompts. It's a repeatable system: collect direction,
assemble the right stack, generate visuals and 3D assets, build in
layers, borrow solved components, and wire up only as much
backend as the project needs. Follow it in order and you stop staring at a
blank editor.
You don't need
To know every line of code before you start. To model 3D assets by hand. To write your own auth
system from scratch. To design a component that's already been solved.
You need
Basic computer skills, patience, strong references, and the ability to explain what you want clearly
— to AI, and to yourself.

02 Generate 3D assets New
Feed a reference image or prompt into Tripo AI to get a ﬁrst 3D model. Bring it into Blender to

03 Animate it
Kling AI or Higgsﬁeld turn a still into a short moving loop. GSAP and Lenis drive on-page scroll
motion; Three.js handles real-time interaction with any 3D asset. Keep movement simple — too
much motion reads as messy.

06 Wire up the backend new phase
Even a "premium" marketing site usually needs somewhere for data to live —
a contact form, a waitlist, gated content, or client accounts. Add only as much
backend as the project actually needs.
Serverless Postgres
Neon
A real Postgres database that spins up per
branch or preview deploy. Pairs naturally with
Next.js API routes or edge functions for forms,
waitlists and simple content.
BaaS
Supabase
Postgres, auth, storage and realtime in one.
The fastest path to client dashboards, e-
commerce accounts, or anything that needs
login and ﬁle uploads out of the box.
Custom service
Spring Boot
A dedicated Java backend for projects with
real business logic — enterprise clients,
internal tools, or anything a serverless
function can't comfortably hold.
Which one, when
Project Reach for
Brand / portfolio site with a contact form Neon + a Next.js API route
E-commerce or client dashboard with login Supabase (auth + storage + DB together)
Enterprise client with custom business logic Spring Boot behind the Next.js frontend
Match the backend to the project. Don't wire a Spring Boot service into a one-page brand site
— that's the same mistake as over-installing tools in phase 02, just further downstream.
07 Ship & glossary
The gap between beginner and premium websites is rarely coding skill. It's
visual direction, consistency, spacing, motion, and typography — held
together with restraint. The best sites are usually the simplest ones. Practice
on real projects; that's how your eye improves.

Quick glossary
Hero section The main top section visitors see ﬁrst.
Prompt Instructions you give to AI.
Component A reusable section, like a form or pricing table.
Motion library A tool used to create animations — GSAP, Motion.dev, Lenis.
glTF / GLB The standard ﬁle format for web-ready 3D models exported from Blender.
BaaS Backend-as-a-service — database, auth and storage bundled, like Supabase.
Responsive design A website that looks right on phones, tablets and desktops.
Edge function A small piece of backend code that runs close to the visitor, not in one central server.
Deploy Publishing your website online.
Localhost Running the site on your own machine before publishing.

03 Lenis Smooth Scroll + GSAP Products Hero
Type: Reusable pinned product-swap hero section | Stack: Next.js 14 · GSAP ScrollTrigger · Lenis
COPY-PASTE PROMPT
Build a reusable premium 'products animation hero' section in Next.js 14 (App Router) + TypeScript +
Tailwind, powered by Lenis smooth scroll and GSAP ScrollTrigger. A pinned hero where one hero product
morphs/swaps through a set of products as the user scrolls, while the page accent colour and background
transition to match each product.
TECH: gsap + ScrollTrigger, @studio-freight/lenis, next/image. Pure DOM + transforms (no 3D), but keep
it 60fps.
LENIS + GSAP SYNC (client provider): const lenis = new Lenis({ lerp:0.1, smoothWheel:true });
lenis.on('scroll', ScrollTrigger.update); gsap.ticker.add(t => lenis.raf(t*1000));
gsap.ticker.lagSmoothing(0); then ScrollTrigger.refresh() after mount.
DATA: array of 4–5 products — { name, image (transparent PNG), accentColor, tagline, price }.
HERO BEHAVIOUR — one pinned ScrollTrigger (pin:true, scrub:1, end long enough for all products):
• The current product sits centre, large. As progress crosses each product's segment, the outgoing
product scales down + rotates slightly + blurs out while the incoming one scales 0.8→1 with a subtle
rotateY tilt and settles — a clean cross-swap, never a hard cut.
• Background + accent tween between each product's accentColor (gsap.to on a CSS variable --accent
that drives background, text and buttons).
• A big index (01/05) and the product name reveal with a masked word animation on each swap
(y:110%→0, overflow hidden).
• Parallax: a soft radial glow and a couple of decorative shapes drift at different scroll speeds behind the
product.
• Left column: animated tagline + price + an 'Add to cart' pill that recolours to the active accent.
EXTRAS: a segmented progress bar (one segment per product) that fills as you pass each; dot navigation
that lenis.scrollTo each segment. On prefers-reduced-motion disable pin/scrub and stack products
statically.
DESIGN: editorial, lots of whitespace, oversized display heading, smooth 0.6–0.9s eases
(power3/power4.inOut). Deliver as <ProductHero products={...} /> plus a LenisProvider and a
useScrollColor helper so I can drop it into any project.

as standard: lenis.on('scroll', ScrollTrigger.update); gsap.ticker.add(t => lenis.raf(t*1000));
gsap.ticker.lagSmoothing(0).
DESIGN AESTHETICS & VIBE
Palette: warm ivory (#FAF7F2) base, soft blush (#F3E6E0) alternating sections, deep espresso text
(#1C1512), and a single champagne-gold accent (#C9A24B) for hairlines, prices and CTAs. Typography:
elegant high-contrast serif display (e.g., Playfair Display / Fraunces via next/font) for headlines, refined
sans (Inter) for body; small widely tracked uppercase overlines (tracking-[0.3em]). Components: pill CTAs,
tall 3:4 portrait product cards (rounded-2xl), thin gold hairline dividers, generous negative space.
Animations (CRITICAL): every section reveals with a soft 'silk' entrance — elements fade from opacity 0,
rise from y: 60, and un-skew from skewY: 4 with a 1.1s power4.out ease, staggered 0.08. Headlines split
into masked lines that slide up (y: 110% → 0, overflow hidden). All product images have a slow Ken-Burns
parallax (scale 1.15 → 1 on scroll) inside overflow-hidden frames. No hard cuts anywhere — every
transition must feel continuous.
